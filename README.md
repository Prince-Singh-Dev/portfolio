# Prince Singh - Portfolio

A static site (plain HTML/CSS/JS, no build step).

## Run locally
1. Open this folder in VS Code.
2. Install the "Live Server" extension.
3. Right-click index.html -> "Open with Live Server".

## Replace project screenshots
Drop your images into assets/projects/ using the exact file names listed in
assets/projects/PUT-SCREENSHOTS-HERE.txt. Add your resume as assets/resume.pdf.

## Edit project data
In index.html, search for `const D=` to edit project names, descriptions, links and tech.
